## Updates

Startup update checks are opt-in. Deskflow reads stable metadata from the official
`deskflow/deskflow` GitHub release and never downloads prereleases.

On supported macOS installations, Deskflow downloads and stages the matching DMG,
verifies its size, SHA-256 checksums, code signature, app version, and notarization,
then asks for confirmation before replacing the app and restarting. Homebrew
installations must be updated with Homebrew.

Windows and Linux checks provide a link to the official release only. They do not
download or run platform installers.
